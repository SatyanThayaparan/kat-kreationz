# Kat Kreationz

Standalone MVP frontend for Kat Kreationz event decor (Vite + React + TypeScript).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm run preview` — preview production build

## Book Now form (MVP)

Frontend-only: validates fields, then offers a `mailto:` draft plus copy-to-clipboard of the inquiry text. Inspiration attachments record filenames only. Replace the placeholder email / connect Formspree (or similar) for production delivery.
